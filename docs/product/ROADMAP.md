# 交付路线图

路线图按受控迭代组织。一轮可以跨越多个工作会话，但只有在实现、验证、档案更新和提交全部完成后才结束。

进度快照（2026-08-10）：第 0–104 轮已在本地完成。当前与历史采用修订都可通过 `plan-outcome-review-v1` 连接生成依据、用户采用的替代和采用后仍确认的训练/恢复记录；历史入口按认证所有者与精确采用修订读取，当前计划推进后旧版本仍可见。解除关联或删除的记录不再作为 Observed 证据，并以撤销计数区别于“从未观察到”；Unknown 与 Observed 仍不推断效果、依从性、因果或自动适应。H5 总量/入口/最大异步块实测为 1,203,055/315,096/200,149 字节，WeApp 总量/vendor/最大页面为 1,104,899/19,338/62,998 字节，全部通过既有入库预算；计划页只余 2 字节，后续功能必须先拆分。生产依赖保持 0 个 critical/high、9 个 moderate。R-030 继续记录恢复状态启发式，R-031 记录七天结果窗口和主动记录选择偏差，风险登记册全表审阅时点仍为第 043 轮。`myfitness-documentation-migration-index/v1` 现在把 `docs/` 下 229 份 Markdown 恰好归类，待迁移总量仍为 191。单元测试 456 项、集成测试 64 项、浏览器测试 95 项。托管质量/冒烟仍只确认到第 030 轮精确 SHA；账号、预算、域名、凭据和付费提供方继续停放，但仍是正式发布门槛。
