# ADR-0130：动作窗口零证据语义

日期：2026-08-11

状态：已采纳

## 背景

动作窗口已经验证数值非负、`sessionCount <= completedSetCount`、跨窗口非递减及 90 日点收据，但单个窗口仍可表示 `sessionCount = 0` 且 `completedSetCount > 0`，或在没有完成组时保留非零次数、负荷、活动时间或距离。

当前 SQL 只有在训练存在已完成组时才计入课次；全部四项测量也只对已完成组求和并在空集合上回退为零。因此这些组合不可能由权威查询产生。反过来，已完成组可能没有次数、负荷、时长或距离测量，不能要求任一测量总计必须为正。

## 决策

1. 保留 `sessionCount <= completedSetCount`。
2. 当 `sessionCount = 0` 时，`completedSetCount` 必须为零。
3. 当 `completedSetCount = 0` 时，`totalReps`、`volumeKg`、`activeMinutes` 与 `distanceKm` 必须全部为零；来源层对对应原始字段执行相同规则。
4. 当 `completedSetCount > 0` 时，不要求任何测量总计为正；全零测量仍是合法证据。
5. 来源冲突统一失败关闭；共享响应 Schema 把错误精确定位到完成组或对应测量字段。
6. 不补造数据、不设置训练量阈值，也不修改 SQL、响应形状、客户端或历史记录。

## 影响

- 空窗口不能再携带幽灵完成组或测量总计。
- 有已完成组但缺少某类可量化测量的训练仍可被忠实表示。
- 规则只验证聚合存在性，不判断动作质量、训练强度、安全性或效果。
- 本决策不证明未截断点聚合与窗口总计一致、训练记录真实或用户理解。

## 备选方案

### 只保留课次不超过完成组

拒绝。零课次仍可携带任意完成组和测量，不能表达 SQL 的空集合语义。

### 有完成组时要求至少一项测量为正

拒绝。时间型、距离型、次数型字段可以合法缺失或为零，完成事实不等于测量覆盖。

### 自动把冲突字段清零

拒绝。静默修正会隐藏来源或替代生产者错误，并改写证据。

## 验证

- 来源层覆盖零课次携带完成组，以及零完成组携带四类非零测量。
- 响应层覆盖同五类失败及精确字段路径。
- 来源与响应都证明有课次、有完成组但四项测量全零保持合法。
- 定向、完整单元、完整集成、严格类型和真实 PostgreSQL 验证通过。
