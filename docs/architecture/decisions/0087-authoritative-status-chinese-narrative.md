# ADR-0087：权威项目状态正文必须以中文完整表达

日期：2026-08-06

状态：已接受

## 背景

第 091 轮把四份活跃权威文档的导航和项目状态总览改为中文，并对新增迭代档案与架构决策建立语言比例门禁。但 `docs/PROJECT_STATUS.md` 的“当前架构”和“当前风险”仍有一百余行英文叙述，实际中文占比只有 4.1%。只检查标题无法证明项目责任人能够用中文审阅当前结构、权限边界和风险。

同时，直接用本地机器翻译覆盖权威状态存在技术语义漂移风险。状态中包含大量代码字面量、Schema、API 路径、数字预算、版本号和历史验证数；翻译准确性不能只由中文字符比例证明。

## 决策

- 逐条人工迁移 `docs/PROJECT_STATUS.md` 的全部当前架构与风险正文，保留原有条目数量、顺序和语义，不压缩或重组产品边界。
- `myfitness-chinese-documentation/v2` 对权威项目状态增加两个门禁：排除代码与链接后的汉字占比至少为 72%；不得存在包含三个及以上英文单词且完全没有汉字的纯英文叙述行。
- 逐行检查跳过围栏代码块和 Markdown 表格分隔行；中文句子中的 Taro、OIDC、API、Schema、工具名与协议名可以保留，不会被当作纯英文叙述。
- 本次迁移把工作区候选与提交前版本比较，要求行内代码字面量、链接目标、围栏代码块和数字令牌的排序多重集合完全一致。该一次性比对是本轮验收证据，不伪装成适用于所有未来内容变更的永久门禁。
- 本地机器翻译候选只能作为非权威参考，必须人工审阅后再以普通补丁采纳。本轮采样出现重复词、错误术语和异常长输出，因此不采用，也不提交其脚本或缓存。

## 影响

权威项目状态现在可以直接用中文审阅，并由 CI 阻止纯英文正文回退。当前实测中文占比为 89.9%，纯英文叙述行为零；迁移范围内 65 个行内代码字面量、70 个数字令牌、链接目标和代码块与迁移前完全一致。

该决策不表示全部活跃文档或历史档案已完成中文化。路线图、架构基线和用户身份运行手册仍有英文正文，需要后续按同样的“机器候选仅供参考、人工校对、结构签名核对、自动语言门禁”流程迁移。
