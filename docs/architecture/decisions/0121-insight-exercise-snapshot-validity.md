# ADR-0121：动作洞察来源快照有效性

日期：2026-08-11

状态：已接受

## 背景

动作洞察 SQL 返回训练保存时的名称、类别、追踪模式、器械和备注快照。纯构造器此前相信 TypeScript 行类型；替代适配器可注入空白或超长文本、未知枚举、重复器械及 `other` 缺少备注。公开 Schema 只能看到未来过滤与 180 点截断后的响应，隐藏第 181 点无法得到同等保护。

这些字段是历史事实，不能通过读取当前动作目录来“修复”，否则目录更正或归档会改写旧训练的含义。

## 决策

- API 构造器把来源行映射为身份对象，并复用公开 `exerciseInsightIdentitySchema` 扫描全部原始动作点。
- 校验发生在未来过滤、顺序、截断和公开映射之前；任一无效快照抛出 `exercise insight point rows must have valid identity snapshots`。
- 名称必须去除首尾空白后为 1–80 字；类别、可空追踪模式和器械使用共享枚举；器械至多六项且不得重复；`other` 必须有 1–120 字备注。
- 共享身份 Schema 同步增加重复器械和 `other`/备注关系门禁，使顶层身份与逐点身份在传输边界独立受检。
- 为兼容旧训练，追踪模式仍可空、器械数组仍可为空。不查询当前目录、不修整来源值、不生成默认值，也不替换历史快照。
- 保持 SQL、响应形状、分页、客户端、目录、持久化、计划、AI 和健康解释不变。

## 影响

无效身份不能通过未来过滤或 180 点截断逃逸，来源构造与公开契约使用同一语义。合法历史快照保持原样，目录后续编辑仍不会重写训练事实。

本决策只证明快照表示符合共享契约，不证明动作名称准确、动作安全、器械适合用户、目录来源可信、记录真实或趋势具有指导意义。
