# ADR-0089：架构基线正文必须以中文完整表达

日期：2026-08-06

状态：已接受

## 背景

第 093 轮完成交付路线图中文化后，`docs/architecture/ARCHITECTURE.md` 仍以英文记录仓库职责、已实现基础、数据不变量、API/事件、AI 执行、安全/隐私和部署目标，中文占比只有约 1.4%。该文件是跨模块实现边界的权威基线；只翻译标题无法让产品与工程责任人用中文完整审阅权限、恢复和数据保管语义。

架构基线包含 Mermaid 图、代码字面量、模型文档链接、ADR 编号和运行时版本。自动覆盖可能翻译技术标识，或把长恢复边界压缩成一般性描述，因此迁移必须逐段人工审阅并独立校验结构。

## 决策

- 逐段迁移架构基线中除 Mermaid 代码块以外的全部自然语言正文，保持条目顺序、信息密度和技术语义；代码、协议、产品与外部专有名词保留原文。
- `myfitness-chinese-documentation/v2` 对架构基线启用最低 72% 中文占比和纯英文叙述行拒绝。
- 迁移候选与提交前版本比较行内代码、Markdown 链接目标、数字令牌和围栏代码块的排序多重集合，四类结构必须完全一致。
- 代码块中的 Mermaid 标签保留原文，以保证图形源码不受自然语言迁移影响；代码块本来也不参与中文比例和纯英文行判定。

## 影响

架构基线当前中文占比为 88.5%，纯英文叙述行为零。正文迁移范围内的 39 个行内代码字面量、15 个链接目标、81 个数字令牌和 1 个 Mermaid 代码块完全一致；本轮状态与治理元数据另行更新。

该决策不改变应用、API、数据库、AI、构建或部署行为。用户身份运行手册与既有历史英文档案仍未完成迁移，不能因三份活跃文档已中文化而声称整个文档库完成。
