# ADR-0088：交付路线图正文必须以中文完整表达

日期：2026-08-06

状态：已接受

## 背景

第 092 轮完成权威项目状态正文中文化后，`docs/product/ROADMAP.md` 仍只有中文标题和进度摘要；0–89 轮范围、退出证据、发布门禁和变更控制均为英文，中文占比只有 5.2%。路线图决定迭代顺序、每轮退出证据和发布条件，是项目责任人日常审阅的第二份活跃权威文档，不能只靠中文导航满足记录要求。

## 决策

- 逐行人工迁移路线图 0–97 轮的范围与退出证据、三个发布门禁和变更控制，保持每个迭代编号、行顺序和历史含义不变。
- `myfitness-chinese-documentation/v2` 对路线图启用与项目状态相同的门禁：排除代码和链接后中文占比至少 72%，且纯英文叙述行为零。
- 迁移候选与提交前路线图做结构签名核对：行内代码、链接目标、围栏代码块和数字令牌的排序多重集合必须一致。`a11y` 等含数字技术缩写不得在翻译中被无声移除。
- 专有名词、协议、产品名和测试缩写保留原文，其他范围、证据和发布要求使用中文完整表达。

## 影响

路线图当前中文占比为 90.6%，纯英文叙述行为零；迁移范围内 107 个数字令牌、链接目标和代码块与迁移前一致，该范围没有行内代码。项目状态和路线图都已进入正文级中文门禁。

架构基线和用户身份运行手册仍有英文正文，不在本决策中扩大为已完成；它们分别进入第 094、095 轮。
