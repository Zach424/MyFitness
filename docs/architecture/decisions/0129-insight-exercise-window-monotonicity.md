# ADR-0129：动作跨窗口聚合单调性

日期：2026-08-11

状态：已采纳

## 背景

动作洞察已固定 7/30/90 日窗口身份，并绑定 90 日课次计数、有限点收据和 `hasMore`。但来源适配器或替代响应仍可能返回彼此不可能同时成立的嵌套窗口，例如 30 日课次少于 7 日课次，或 90 日完成组、次数、负荷、活动时间和距离小于 30 日。

SQL 审计确认六个字段都使用同一用户、动作键、参考时刻和已完成组资格。所有被求和的训练数值已有非负来源门禁；窗口范围随 7→30→90 日扩大，因此这些聚合都具有集合包含下的非递减性。

## 决策

1. 来源层先把缺失的 7/30/90 日窗口按既有语义归一为六项全零，再按固定顺序比较相邻窗口。
2. `session_count`、`completed_set_count`、`total_reps`、`volume_kg`、`active_seconds` 与 `distance_meters` 随窗口增大都不得减少。
3. 共享响应 Schema 独立验证对应的 `sessionCount`、`completedSetCount`、`totalReps`、`volumeKg`、`activeMinutes` 与 `distanceKm`，并把问题定位到较长窗口的精确字段。
4. 任一冲突失败关闭；不从公开点前缀重算窗口、不补造活动，也不修改 SQL、响应形状、分页、客户端或历史记录。
5. 该规则只验证嵌套集合关系，不生成训练改善、动作质量、效果或因果解释。

## 影响

- 7/30/90 日动作窗口不能再表达违反同一非负集合包含关系的聚合减少。
- 较短窗口为空时仍允许较长窗口出现训练，保留稀疏来源的可逆回退。
- 相邻比较通过传递性覆盖 7→90，同时保持实现和错误路径最小。
- 本决策不证明单窗口零证据语义完整、训练记录真实、动作执行安全、趋势意义、训练效果或用户理解。

## 备选方案

### 只校验 `sessionCount`

拒绝。完成组和五项求和字段仍可能违反同一嵌套集合。

### 从公开训练点重算窗口

拒绝。超过 180 个训练时公开点只是有限前缀，不能代表完整窗口。

### 要求三个来源窗口必须全部存在

拒绝。现有来源边界允许缺行回退；零聚合短窗口可以被非空长窗口包含。

## 验证

- 来源层逐项覆盖课次、完成组、次数、负荷、活动时间和距离在较长窗口减少。
- 响应层逐项覆盖同六类失败及精确字段路径。
- 定向、完整单元、完整集成、严格类型和真实 PostgreSQL 验证通过。
- 既有双端产物预算与生产依赖审计继续通过。
