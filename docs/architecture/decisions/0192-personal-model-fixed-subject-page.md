# ADR-0192：Personal Model 固定主题读取页面

日期：2026-08-12

状态：已接受

## 背景

第 196 轮已经提供当前主题的页面内存读取权限，第 197 轮已经提供中性展示模型与 props-only 卡片，但用户仍没有可进入的 Personal Model 页面。直接把共享根契约的 Zod Schema 引入延迟页面，会让 H5 路由块增长到约 562 KiB；同时，原 WeApp 总量预算只比未接线基线多 1,888 字节，无法容纳一个真实页面。

本轮只开放 `training.recorded_frequency`，验证进入读取、刷新、失败重试、旧快照保留和卸载失权的最小用户闭环。训练安排、课次时长、反馈、历史、lineage、证据分页、回顾、模型导出和持久缓存继续排除。

## 决策

1. 新增独立路由 `pages/personal-model/index`，从“我的衡迹”第三个权限入口进入；入口明确写成“认知镜子”，不伪装成完整 AI 教练。
2. 页面主题固定为 `training.recorded_frequency`，进入时只读取一次。刷新和失败重试均由用户显式触发，不轮询、不后台重放、不批量读取其他主题。
3. 页面复用既有 unread/五阶段读取状态、单调代次收据和中性展示卡片。刷新期间保留整份上次成功快照；刷新失败显示 stale 文案，初始失败不显示空主题或零值。
4. 卸载时先撤销页面活动权限，再使读取代次失效；迟到成功或失败均不能提交状态或调度焦点。
5. 客户端 unknown 响应边界改用 `@myfitness/contracts/personal-model-current-subject.runtime` 的无第三方依赖严格校验器。它保持精确键、枚举、数值、时域、证据计数、状态、三种 claim 与跨字段不变量，并以 Zod 权威 Schema 的同意测试覆盖空态、三个合法主题和畸形反例。
6. Zod 根 Schema 继续作为服务端、测试和类型权威；轻量校验器只服务受包体约束的客户端响应边界，不能自行扩展契约。契约变更必须同时更新两者并通过一致性测试。
7. 页面视觉延续矿蓝/杜松绿/警示色和证据刻度。页面主叙事强调“系统看见的是记录，不是用户全部”，固定边界说明未开放能力；360 px 下不得产生水平溢出。
8. 先移除意外 Zod 路由膨胀，再按真实页面净成本校准 WeApp 总量预算：从 1,107,000 调整为 1,150,000 字节。实测总量为 1,146,581 字节，只保留 3,419 字节余量；vendor 19,338 和最大页面 56,943 字节的既有门槛不放宽。

## 影响

- 用户首次可以进入一个真实 Personal Model 页面，并区分加载、可信结果、刷新保留和失败，不再只有不可达的技术链。
- 页面只开放一个主题，避免一次读取把三个主题拼成看似完整的人格画像，也让状态权限先获得独立证明。
- 轻量校验器消除了客户端对 Zod 运行时的依赖；H5 最大异步块保持 149,898 字节，低于 152,000 门槛。
- 双实现契约带来漂移风险，因此一致性测试成为必要门禁。它证明已列夹具一致，不是形式化等价证明。
- WeApp 总量预算发生一次有证据的产品能力校准；后续不能用该决策掩盖根依赖误入、重复页面代码或无界增长。

## 备选方案

### 直接在页面使用共享 Zod Schema

拒绝。初次构建把 H5 最大异步路由推到约 562 KiB，明显超过 152,000 字节门槛；页面并不需要把完整服务端契约运行时带到设备。

### 把三个主题同时接入一个页面

拒绝。会同时扩大读取编排、切换竞态、状态语义和用户理解范围，无法保持本轮可逆的单一变更。

### 不调整 WeApp 总量预算

拒绝。新路由自身 JS/WXSS/配置约 39 KiB，未接线基线只有 1,888 字节余量；在已经消除依赖泄漏后，强行维持旧线只会阻止任何真实页面进入产物。

### 使用持久缓存改善失败体验

拒绝。Personal Model 是敏感派生数据；当前页面内存旧快照已经覆盖同次会话刷新失败，跨会话保留需要独立的保留、清除和共享设备决策。

## 验证

- 轻量运行时一致性测试覆盖空态、三个合法主题和十一组畸形边界；页面模型、结构、读取权限、适配器与展示定向测试通过。
- 完整单元测试 115 个文件、698 项通过；完整 PostgreSQL 集成测试 29 个文件、174 项通过。
- 全工作区 typecheck、H5/API/admin/WeApp 构建及生产依赖审计通过。
- H5 总量/入口/最大异步块为 1,247,931/315,456/149,898 字节；WeApp 总量/vendor/最大页面为 1,146,581/19,338/56,943 字节。
- 本地浏览器验证加载态和离线失败态，360 px 视口无横向溢出，重试可见且控制台无错误；没有真实认证 API，因此不据此声称成功快照已完成浏览器证明。
