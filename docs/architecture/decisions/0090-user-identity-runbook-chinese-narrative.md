# ADR-0090：用户身份运行手册正文必须以中文完整表达

日期：2026-08-06

状态：已接受

## 背景

前三轮已依次完成项目状态、交付路线图和架构基线正文中文化，但 `docs/operations/USER_IDENTITY_RUNBOOK.md` 仍以英文记录微信与 H5 OIDC 的信任边界、生产配置、共享环境预检、事件轮换和回滚。该手册直接约束真实凭据、身份提供方和账号擦除操作；只有中文标题不足以支持责任人安全执行。

手册包含四个配置/命令代码块、环境变量、API 路径、HTTP 状态码、迁移编号与外部规范链接。翻译不能改变命令字节、操作顺序或失败关闭语义。

## 决策

- 逐段迁移身份运行手册的全部自然语言正文，保留配置/命令代码块、环境变量、API 路径、协议名和外部专有名词。
- `myfitness-chinese-documentation/v2` 对该手册启用最低 72% 中文占比和纯英文叙述行拒绝，使四份活跃权威文档全部进入正文级门禁。
- 提交前版本与候选版本比较行内代码、链接目标、数字令牌和围栏代码块的排序多重集合；四类结构必须完全一致。
- 迁移不放宽任何真实提供方、域名、凭据、设备、共享环境或数据保管预检；本地替身证明不得扩大为生产证明。

## 影响

用户身份运行手册当前中文占比为 73.0%，纯英文叙述行为零。迁移前后的 42 个行内代码字面量、8 个链接目标、43 个数字令牌和 4 个配置/命令代码块完全一致。

四份活跃权威文档现在都能用中文完整审阅并由 CI 防止大段英文回退。专题模型、早期运行手册、0–89 轮迭代档案和 ADR-0001–0084 仍大多为英文，需要后续受控批次；本决策不把它们标记为完成。
