# ADR-0093：中文文档迁移范围必须完整、唯一且失败关闭

日期：2026-08-06

状态：已接受

## 背景

中文记录门禁已经保护活跃权威文档、第 090 轮以后的迭代档案和 ADR-0085 以后的决策，但“专题模型、历史迭代和早期 ADR 后续迁移”仍只是文字待办。仓库包含两百余份 Markdown；如果没有精确清单，新增文件可能永远不进入迁移范围，同一文件也可能在多个批次中重复计算，历史编号缺失或索引计数陈旧不会自动暴露。

迁移范围完整不等于翻译完成，更不等于语义保真。检查器需要解决的是集合与顺序问题，同时继续把翻译准确性、术语一致性、代码字面量、链接、数字和历史结论交给每轮人工审阅。

## 决策

- 新增 `docs/DOCUMENTATION_MIGRATION_INDEX.md` 作为第五份活跃权威文档，登记三个专题批次、六个历史批次和 193 份待迁移文件；它由现有中文正文门禁检查标题、正文比例和纯英文叙述行。
- 新增无第三方运行时依赖的 `myfitness-documentation-migration-index/v1` 检查器，递归扫描 `docs/` 下全部 Markdown，并要求每份文件恰好归入活跃权威、治理规范、待迁移专题、待迁移历史或当前受保护序列之一。
- 专题批次使用 19 个精确路径；历史批次使用迭代 000–089 和 ADR-0001–0084 的六个不重叠闭区间。检查器要求区间内每个编号存在且唯一。
- 第 090 轮以后的迭代档案与 ADR-0085 以后的决策自动进入连续受保护序列；从起点到当前最大编号不得有缺口或重复。内容是否中文合格仍由 `myfitness-chinese-documentation/v2` 决定。
- 索引必须保留 Schema、精确待迁移总量、所有批次 ID 和全部专题链接。新增漏网文件、重复归类、登记但缺失的文件、历史编号缺口或陈旧索引均失败关闭。
- `pnpm docs:check-migration-index` 进入主 CI，位于中文正文门禁之后、依赖审计之前。单元测试覆盖通过路径、漏项、重复归类、历史缺号和陈旧索引。
- 本轮只建立范围权威，不翻译既有历史正文，也不把任何待迁移批次标记为完成。

## 影响

后续迁移可以从明确的 193 份待办中选择一个文件或连续编号小批次，不再依赖记忆或模糊目录描述。新增 Markdown 必须同时决定它属于活跃、治理、待迁移还是受保护范围，否则 CI 立即失败。

该机制会要求每次完成迁移批次时同步修改索引策略和中文保护范围，这是刻意的变更成本。检查结果只证明文件集合完整、编号连续和索引未陈旧；每份文档仍需保留技术字面量与历史语义，并通过人工审阅后才能改变状态。
