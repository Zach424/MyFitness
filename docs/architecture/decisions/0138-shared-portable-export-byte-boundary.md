# ADR-0138：便携导出共享字节边界与服务端拒绝收据

日期：2026-08-11

状态：已采纳

## 背景

便携导出 API 从 repeatable-read PostgreSQL 快照构造 `myfitness-portable-export-v4`，格式化为 JSON 后放入内存 `Buffer` 并作为附件返回。客户端已经在 H5 下载或 WeApp 保存前按 UTF-8 拒绝超过 50 MiB 的文件，但上限是客户端本地常量，服务端不会在传输前拒绝超限产物。大账号因此可能消耗网络与客户端临时存储后才失败，API 和客户端也可能因独立修改而产生边界漂移。

当前同步实现会在内存中持有数据库结果、JavaScript 对象图和格式化 JSON 字符串。本轮可以阻止超限附件继续分配与传输，但不能在不改变导出架构的情况下消除前面的内存峰值。风险边界必须把“交付上限”与“流式/异步归档”分开声明。

## 决策

1. 在 `packages/contracts` 定义唯一 `maximumPrivacyExportBytes = 50 * 1024 * 1024`，即 52,428,800 字节；API 和客户端都从该常量读取，不保留第二份数值。
2. 同一共享契约定义稳定错误码 `portable_export_too_large` 和严格 413 响应 Schema：`statusCode`、`code`、非空 `message` 与 `maximumBytes`。
3. API 保持现有格式：`JSON.stringify(payload, null, 2)` 后追加一个换行。服务端先用 `Buffer.byteLength(serialized, 'utf8')` 测量最终字符串，不以 UTF-16 字符数、数据库行数或估算值代替。
4. 精确字节数大于共享上限时，服务端在分配附件 `Buffer` 前抛出 413，响应只含固定收据，不包含账号标识、导出内容或内部行数据；不自动重试或降级为不完整导出。
5. 精确等于上限时允许；成功附件显式设置与实际 `Buffer` 相等的 `Content-Length`，继续使用 JSON 媒体类型、附件文件名和 `private, no-store`。
6. 客户端保留独立落盘前验证，继续检查媒体类型、v4 信封、集合拓扑、标识符、时间和相同 UTF-8 上限。服务端成功不替代客户端保管边界。
7. OpenAPI 和中文接口参考必须公开 413 错误码与上限；R-013 只记录缓解增强，不关闭。
8. 本轮不实现流式响应、后台任务、压缩、加密、云归档、限时链接、部分导出或真实微信设备操作。

## 影响

- API 与客户端不会再因常量复制产生交付上限漂移。
- 超限响应不会分配第二份附件 `Buffer`、不会传输大文件，也不会被客户端写入下载/保存位置。
- 正常附件的字节长度可由 HTTP 头、实际正文和客户端收据交叉验证。
- API 仍会先读取全部导出行并构建对象图与格式化字符串；超限门禁降低后半段资源消耗，但不是内存上界或可扩展归档方案。
- 413 是确定性资格拒绝。客户端不得把它视为未知提交或盲目重试；未来应引导到异步归档流程。

## 备选方案

### 只保留客户端上限

拒绝。它不能阻止服务端附件分配、网络传输和临时文件占用，也允许两端数值漂移。

### 用 JavaScript 字符串长度判断

拒绝。字符串长度是 UTF-16 代码单元数，不等于中文、表情等内容的 UTF-8 附件字节数。

### 超限后截断集合或删除照片

拒绝。静默部分导出会破坏用户数据所有权和 v4 完整性声明，也无法提供可靠缺失收据。

### 本轮直接实现异步加密归档

暂不采用。该方案需要持久任务、对象存储、密钥/保留策略、下载授权、过期与删除责任，属于需要产品与外部基础设施决策的独立迭代。

### 在生成字符串后仍先创建 Buffer 再判断

拒绝。虽然结果正确，但超限路径会额外分配最多数十 MiB 的附件副本；先用 `Buffer.byteLength` 可避免这一步。

## 验证

- 共享契约测试锁定 52,428,800 字节、错误码和严格 413 收据。
- 服务端纯测试证明格式化 JSON、末尾换行、中文 UTF-8、精确上限可接受，以及超出一字节时返回固定 413 且不回显 payload/data。
- 真实 PostgreSQL 隐私导出测试证明合法 v4 附件继续返回，`Content-Length` 等于实际 UTF-8 正文且不超过共享上限。
- OpenAPI 生成物必须包含 413、`portable_export_too_large` 与精确最大字节数。
- 双端生产构建和客户端质量门禁必须证明共享常量没有突破 H5/WeApp 预算。
- 完整格式、类型、单元、集成、生产依赖、中文文档、迁移索引与 Obsidian 门禁通过后才允许提交。
