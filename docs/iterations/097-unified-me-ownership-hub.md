# 第 097 轮：统一“我的”所有权入口

日期：2026-08-06

状态：已完成

## 1. 范围与验收标准

本轮只把首页“我的”从隐私页直达补成一个本地统一入口；不新增资料/授权 API、缓存、云服务或账户操作。验收要求是：资料/目标/单位/时区/安全边界与授权/导出/删除按两个权威范围出现且不重复；入口不声明完成率、零数据、授权状态或操作可用性；两张卡只进入现有建档和隐私页面，返回后仍停留在“我的”；320 px 与 1280 px 无水平溢出或固定导航重叠；受影响的隐私流程、双端构建与包体门禁通过；状态、路线图、架构、ADR、Obsidian 和 Git 同步完成。

## 3. 实现方法

### 只编排，不汇总敏感状态

“我的”目录只从入库常量渲染能力、说明和两个允许的路由。它没有 `useEffect`、API 客户端、账号标识或本地存储，也不读取首页仪表板；因此进入目录不会产生资料或保管清单请求。真正的当前修订、确认缺失、授权和数据数量仍由建档/隐私页面独立读取并决定权限。

### 把破坏性能力留在权威页面

目录可以说明“账户删除”存在，但按钮只写“打开数据保管台账”。导出、撤回和删除控件仍位于隐私页，并继续受当前保管快照、确认短语、对账和生命周期门禁保护。资料卡同样只进入完整三步底稿，不在目录提供快捷修改。

### 使用页面栈恢复来源

建档和隐私页面都继续调用 `navigateBack()`，只把可访问名称改成“返回上一页”。因此从今日头像、进度照片或“我的”进入时无需在 URL 记录来源，也不会在敏感页面持久化导航上下文。真实浏览器证明两个入口返回后仍保留“我的”标签。

### 让真实增量决定预算

初次构建在原预算下以 H5 `2,838,465 > 2,835,000` 失败。相对第 096 轮，H5/WeApp 实际增加 6,555/7,309 字节；总量预算分别只增加 7,000/8,000 字节至 2,842,000/1,098,000。H5 入口/最大异步块继续为 319,238/205,756 字节，WeApp vendor/最大页面继续为 19,338/55,697 字节，因此关键峰值没有扩大。

## 5. 发现的问题与经验

- “我的”不是“隐私”的同义词。资料决定产品如何服务用户，数据保管决定服务可以保存和处理什么；统一入口应解释二者关系，而不是把两个权威模型合并。
- 在目录页显示“资料已完成”或“当前无授权”看似友好，却会立即引入组合读取、失败与旧快照问题。没有明确任务需要时，零读取的导航目录更诚实。
- 返回按钮写死目的地会在新增入口后变成事实错误。使用平台页面栈时，可访问名称也应表达“上一页”，除非代码确实执行固定路由替换。
- 同路由组件仍有真实包体成本，但删除废弃占位状态可以抵消一部分。是否接受增量应看入口和单块峰值，而不只看总文件树。
- Taro 自定义按钮在 CLI 指针命令下可能等待元素重渲染而超时；通过最新语义快照定位后调用同一元素的原生点击可以稳定验证路由，正式回归仍由仓库内 Playwright 测试覆盖。

## 6. 全局状态、剩余风险与下一步

首页五个主要导航现在都具有符合产品简报的问题入口：今天看事实，记录保存事实，计划管理本周，教练解释证据与计划，我的管理资料依据和数据保管。统一目录没有扩大任何敏感读取或变更权限，真实身份、生产存储和政策材料的外部门禁保持不变。

下一轮继续选择一个不依赖外部输入的有界改进，优先建立剩余中文专题/历史档案索引，避免长期记录迁移失去可核对范围。托管共享环境部署顺延至第 098 轮，等待云账号、域名、凭据、责任人和政策材料；原生设备同步顺延至第 099 轮。
