# 第 098 轮：中文文档迁移索引与范围门禁

日期：2026-08-06

状态：已完成

## 1. 范围与验收标准

本轮只把剩余中文文档迁移范围变成机器可核对的权威索引；不翻译既有专题或历史正文，也不修改产品运行行为。验收要求是：`docs/` 下每份 Markdown 恰好归类一次；19 份专题路径存在，迭代 000–089 与 ADR-0001–0084 连续且无重复，第 090 轮与 ADR-0085 以后自动进入受保护序列；索引的 Schema、193 份待迁移总量、批次 ID 和专题链接不可陈旧；新命令进入 CI；索引自身通过中文门禁；状态、路线图、架构、ADR、Obsidian 和 Git 同步完成。

## 2. 项目结构、设计、技术与实现功能

- `docs/DOCUMENTATION_MIGRATION_INDEX.md`：第五份活跃权威文档，列出三个专题批次、六个历史批次、精确文件链接、顺序、退出条件和自动检查边界。
- `scripts/docs-migration-inventory.mjs`：Node.js 标准库检查器，递归扫描全部 Markdown，验证集合分区、精确路径、连续编号和索引受控标记。
- `scripts/docs-migration-inventory.test.ts`：五项 Vitest，覆盖完整清单、未归类文件、历史缺号、重复归类和陈旧索引。
- `scripts/docs-language-policy.mjs`：把迁移索引加入活跃权威文档，要求七个中文导航标题、至少 72% 中文占比和零纯英文叙述行。
- `docs/DOCUMENTATION_LANGUAGE_POLICY.md`：把活跃文档数量更新为五份，并要求每次迁移同步更新索引、检查策略和保护范围。
- `package.json`：新增 `pnpm docs:check-migration-index`。
- `.github/workflows/ci.yml`：在中文正文检查之后执行迁移范围门禁。

## 3. 实现方法

### 把全部 Markdown 建模为互斥分区

检查器先递归收集 `docs/` 下所有 `.md` 文件，再分别登记五份活跃文档、一份治理规范、三个专题批次、六个历史批次和两个当前受保护序列。每个文件保留分类列表；列表为空即漏项，超过一项即重叠。显式登记但磁盘不存在也立即失败，因此删除或改名不能让索引静默漂移。

### 同时验证历史闭区间与未来连续性

待迁移历史固定为迭代 000–029、030–059、060–089 和 ADR-0001–0028、0029–0056、0057–0084。检查器逐个编号要求恰好一个文件。第 090 轮和 ADR-0085 以后不需要每轮修改文件列表，但从起点到当前最大编号必须连续；新增第 098 轮和 ADR-0093 后自动得到 090–098 与 0085–0093 两个九文件序列。

### 让人读索引和机器策略相互约束

人读索引提供文件链接、迁移顺序和退出条件；代码策略提供精确集合。检查器反向要求索引包含 Schema、193 份总量、九个批次 ID 和 19 个专题链接。只修改其中一侧会失败，避免表格长期与真实目录分离。

### 分开“范围完整”和“正文合格”

新门禁不计算待迁移文档的中文比例，也不宣布它们完成；现有 `myfitness-chinese-documentation/v2` 继续负责活跃文档和新记录。索引成为第五份活跃文档后，实测中文占比 94.4%，纯英文叙述行为零。未来批次只有在逐份语义审阅后才会从待迁移转入受保护范围。

## 5. 发现的问题与经验

- “以后再迁移整个目录”不是可执行计划。目录内同时存在活跃中文文档、已受保护的新记录和待迁移历史，必须先建立互斥分区。
- 只列文件数不够；精确路径能发现专题改名和删除，连续编号能发现历史缺口，两者解决不同问题。
- 自动接纳未来编号可以避免每轮维护长列表，但必须从受保护起点检查到最大编号，否则中间漏档会被掩盖。
- 人读索引和代码配置不可完全独立。互相检查关键标记可以用很小成本避免“文档说 193、代码扫描 192”一类漂移。
- 范围门禁只回答“有哪些文件”，不能回答“翻译是否正确”。迁移轮次仍必须比较链接、代码、数字和历史语义，不能用通过脚本代替审阅。

## 6. 全局状态、剩余风险与下一步

中文治理现在同时覆盖新内容质量和旧内容迁移范围。仍待迁移的 193 份文档没有被虚报为完成，但已经具备明确批次、文件归属和失败关闭保护；任何新增文档都必须立即进入一个已知范围。

下一轮第 099 轮优先迁移 `docs/product/PRODUCT_BRIEF.md`，一次处理产品定位、初始受众、核心工作、MVP 范围、明确排除、成功模型与商业假设，并对列表、数字和术语做结构保真核对。托管共享环境部署顺延至第 100 轮，等待云账号、域名、凭据、责任人和政策材料；原生设备同步顺延至第 101 轮。
