# 第 095 轮：用户身份运行手册正文中文化

日期：2026-08-06

状态：已完成

## 1. 范围与验收标准

本轮只迁移 `docs/operations/USER_IDENTITY_RUNBOOK.md` 的状态、信任边界、配置、共享环境预检、事件轮换、回滚与主要参考，并把中文正文门禁扩展到该手册；不修改身份运行时、提供方配置值、命令代码块或历史英文档案。验收要求是：操作语义、顺序和失败关闭边界用中文完整表达；行内代码、链接目标、数字令牌和代码块不漂移；手册中文占比至少为 72%，纯英文叙述行为零；状态、路线图、架构、规范、ADR 和档案同步更新；完成全量单元、类型、格式、语言和生产依赖审计；状态与档案同步到 Obsidian；最后提交并推送。

## 3. 实现方法

### 保留身份权威与秘密边界

译文继续明确客户端不是身份权威、API 才能交换和验证提供方凭据、浏览器只能获得公开安全配置。`openid`、issuer、subject、nonce、verifier、AppSecret 和客户端秘密的禁止接收/记录规则逐项保留。

### 保持操作顺序和失败关闭

共享环境预检的十个步骤保持原顺序，事件处理继续区分 `400`、`401`、`403` 与 `503`，回滚继续禁止重启 `dev`、移除抑制或削弱令牌验证。翻译没有把本地替身证据扩大为真实设备或生产提供方证明。

### 对命令与引用做结构签名

四个 dotenv/PowerShell 代码块逐字节保持不变；行内代码、链接目标与数字令牌分别比较排序多重集合。迁移后手册实测 1,617 个汉字、598 个拉丁字母，中文占比为 73.0%，纯英文叙述行为零。

## 5. 发现的问题与经验

- 身份手册中的 code、state、nonce、issuer、subject 等词是协议或字段字面量；保留英文比生硬翻译更安全，但必须放在中文操作句中解释其权限关系。
- 中文占比 73.0% 高于门禁但低于其他活跃文档，原因主要是配置块外仍需保留大量 OIDC、URL、HTTP、API 与环境变量名称；门禁排除代码与链接后仍能防止正文回退。
- 操作手册最重要的是顺序与禁止项。逐步迁移和数字/代码块签名可以防止漏掉迁移号、状态码或预检步骤。
- 四份活跃权威文档完成不等于 204 份 `docs/` Markdown 全部完成；历史审计记录必须明确列为剩余工作。

## 6. 全局状态、剩余风险与下一步

项目状态、交付路线图、架构基线和用户身份运行手册现在都可用中文完整审阅，并由本地/CI 门禁阻止英文正文回退。真实微信/OIDC 提供方、域名、凭据、设备和共享环境证明仍未完成，本轮没有改变其发布门禁。
