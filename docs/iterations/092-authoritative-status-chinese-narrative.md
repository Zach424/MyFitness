# 第 092 轮：权威项目状态正文中文化

日期：2026-08-06

状态：已完成

## 1. 范围与验收标准

本轮只迁移 `docs/PROJECT_STATUS.md` 的“当前架构”和“当前风险”正文，并把中文文档门禁扩展到权威状态全文；不修改客户端、API、数据库、AI、部署运行时或其他三份长文档。验收要求是：每条当前架构与风险语义都用中文完整表达，原有条目数量和顺序不变；技术字面量、链接、代码块、版本号、预算和历史验证数字不漂移；权威状态排除代码/链接后的汉字占比至少为 72%，纯英文叙述行为零；新增检查有正反单元测试；项目状态、路线图、架构决策和中文记录规范同步更新；完成全量单元、类型、格式、语言与生产依赖审计；状态和本轮档案同步到 Obsidian 并逐字节核验；最后以一次 Conventional Commit 提交并推送。

路线图、架构基线、用户身份运行手册和 0–89 轮历史档案不在本轮迁移。它们继续作为明确待办分轮处理，不能因项目状态已中文化而声称整个文档库已经完成。

## 2. 项目结构、技术与设计状态

- `docs/PROJECT_STATUS.md`：当前架构的 84 条能力/权限边界与 38 条风险全部使用中文叙述；代码标识符、协议、工具名和审计原始级别保留。
- `scripts/docs-language-policy.mjs`：门禁升级为 `myfitness-chinese-documentation/v2`，为权威状态增加最低 72% 中文占比和纯英文叙述行检测。
- `scripts/docs-language-policy.test.ts`：新增技术词允许/纯英文行识别，以及活跃权威正文回退拒绝用例。
- `docs/DOCUMENTATION_LANGUAGE_POLICY.md`：记录正文门禁、一次性技术结构签名核对和人工校对要求。
- `docs/architecture/decisions/0087-authoritative-status-chinese-narrative.md`：固定本轮迁移边界、门禁语义和机器翻译只可作为非权威参考的原则。
- `docs/product/ROADMAP.md`：把第 092 轮标记为权威状态正文迁移，并将其余三份活跃文档拆成第 093–095 轮。

本轮不引入运行时依赖。语言检查仍是 Node.js ESM 无第三方依赖脚本；所有检测只读取仓库 Markdown，不访问用户数据、网络或 Obsidian。

## 3. 实现方法

### 逐条翻译而不压缩架构语义

当前架构不是普通说明文字，而是九十余轮实现积累的权限、恢复、隐私和发布边界。本轮保持每条原始项目符号的位置和信息密度，只把自然语言迁移为中文。`current`、`revoked`、API 路径、Schema 版本、命令、环境变量和代码属性继续以原字面量存在，避免译文与实现脱节。

### 用整体比例和纯英文行双重失败关闭

整体比例能发现大面积语言回退，但中文标题可能掩盖一条完整英文正文。因此 v2 除了要求项目状态汉字占比至少 72%，还逐行移除围栏代码、行内代码、链接与 URL；剩余内容如果包含至少三个英文单词且没有汉字，就作为纯英文叙述失败。中文句子内的 Taro、React、OIDC、API、Schema 等术语合法。

### 把技术结构与数字作为独立验收

本轮用提交前 `HEAD` 和工作区候选分别提取行内代码、Markdown 链接目标、围栏代码块与数字令牌，按排序多重集合比较。首次比较发现译文把英文拼写数词改成阿拉伯数字，并给 `deterministic-v1` 新增反引号；随后改用中文数词并恢复原标记，最终四类集合完全一致。该检查验证结构保持，不证明自然语言翻译准确，因此仍逐条人工审阅。

### 拒绝低质量机器候选

工作区外的本地模型采样只写临时目录，但缓存样本出现“计划计划计划”“录音记录”长重复和术语损坏。本轮不把候选、翻译脚本、缓存或模型产物加入提交，而是使用人工补丁。经验被写入 ADR，后续迁移仍可用机器候选辅助定位，但不得自动覆盖权威文档。

## 5. 发现的问题与经验

- 中文标题和少量中文摘要会让“看起来已经中文化”的印象远强于真实状态；4.1% 的初始占比说明必须量化全文，而不只检查导航。
- 机器翻译失败不只是文风问题：重复、错义和技术占位符损坏会改变权威状态。权威迁移必须人工校对，并独立核对结构签名。
- 数字语义需要同时保护阿拉伯字面量和英文拼写数词。把 “five” 翻成“五”可保持数字令牌集合；翻成 `5` 虽语义相同，却会扩大不可审阅的结构差异。
- 纯英文行检测采用“至少三个英文单词且零汉字”，可以阻止整句回退，同时允许中文句子保留必要技术名；该启发式仍不能判断译文质量。
- 将一份长权威文档作为单轮边界，能够完成逐条审阅、签名对比和可读提交；把四份长文档同时翻译会失去这种可核验性。

## 6. 全局状态、剩余风险与下一步

仓库的唯一权威项目状态现在可由中文完整审阅，并由本地/CI 门禁阻止恢复成大段英文。功能、架构、隐私、部署和风险语义没有被压缩；产品仍处于内部 Alpha，真实身份、云数据保管、域名、遥测、政策和提供方验证仍未完成。
