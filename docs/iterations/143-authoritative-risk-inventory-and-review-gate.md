# 第 143 轮：权威风险库存与全表审阅门禁

日期：2026-08-11

状态：已完成

## 1. 范围、分类与验收标准

本轮分类为 R（Risk Reduction）。范围只包含产品风险登记册 30 项开放风险的时效、严重度、仓库证据、外部责任前提与关闭条件复核，以及防止库存再次静默漂移的中文文档门禁；不包含外部账号、云资源、真实 API、真实设备、用户研究、专家审阅或生产发布。

验收标准固定为：逐项审阅所有开放风险；明确报告总数、高/中分布和新增/关闭/升降级数量；只修正有仓库证据支持的过期描述；需要真实身份、设备、数据、用户、专家、政策、责任人、托管资源或发布材料的风险全部保持开放。自动检查必须锁定最新审阅标记、30 个精确编号与顺序、20 项高/10 项中，并用负向测试证明编号或顺序漂移失败关闭。新增恰好一份本轮档案和一份对应 ADR，完成完整验证、Obsidian 同步、提交与远端核验。

## 2. 项目结构、设计、技术与实现功能

- `docs/product/RISK_REGISTER.md`：把全表审阅推进至第 143 轮，登记 30 项全部开放、20 高/10 中以及零新增/关闭/升降级；更新 R-022、R-024、R-029 的当前控制与剩余门禁。

- `scripts/docs-language-policy.test.ts`：新增库存统计正向测试和编号/顺序漂移负向测试，既有中文元数据、正文比例、受控标记和禁用等级测试保持通过。

## 3. 实现方法

### 全表逐项审计而不是沿用局部备注

先从 Markdown 表格独立解析全部风险，得到 30 个编号、20 项高和 10 项中；再逐行核对风险事实、当前控制、下一门禁与关闭所需证据。R-002 至 R-032 中只有历史未使用的 R-018 缺位，缺口保持不复用。

### 把仓库控制与外部证明分开

R-022 的精确标签/main/CI、不可变 Actions、服务/客户端/环境准入已有可复现仓库证据，因此从“下一候选”移到“当前控制”；账号、预算、域名、凭据、材料、责任人、金丝雀和回滚仍无真实证明。R-024 明确本地资格工具已经存在，但已发布的 `v0.1.0-rc.1` 仍缺这些资产，也没有真实新候选。R-029 只修正服务端 SQL 已完成的时态，不扩大到平台 IANA 或真机证明。

### 预期库存而不是自洽计数

检查器会动态解析表格并返回实测库存，但通过条件使用显式预期编号和严重度数量。仅做动态计数时，误删一行后文档仍可能以较小总数自洽；显式预期值要求任何合法新增、关闭或改级都在同一轮更新治理决策和证据。

### 编号顺序与历史空缺一起锁定

门禁比较完整有序编号列表，而不只比较总数。这样既能阻止重复、漏项和重排，也能阻止将 R-018 悄悄分配给新风险。未来新增风险应使用下一个新编号。

### 不从本地绿色门禁推导风险关闭

自动检查证明登记册结构与声明一致，不证明真实世界条件成立。所有需要外部责任与发布材料的行继续开放；本轮没有为了制造“风险下降”而降低等级或缩小风险事实。

## 5. 发现的问题与经验

- 局部风险备注不能代替定期全表复核；一项过期“下一门禁”会掩盖真正剩余的外部责任。
- 风险事实、当前控制、下一门禁和关闭证据是四个不同层次；仓库实现只会改变其中一部分。
- 仅校验标题、中文比例和固定句子不足以治理结构化登记册；关键表格需要领域级不变量。
- 动态汇总适合报告，显式预期库存适合失败关闭。两者同时存在才能既可观察又可控。
- 历史空缺也是审计事实；复用编号会让旧文档、讨论和发布材料产生歧义。
- 风险复核的价值不是让数字下降，而是让每项风险的真实剩余工作、责任与证据边界保持准确。
- 用户要求暂缓的云服务、真实 API 与手动配置可以继续停放，但必须在风险表和发布门禁中保持可见。

## 6. 全局状态、项目反思与下一步

本轮恢复了风险登记册的全表时效，并把开放库存、严重度与审阅结论纳入可复现门禁。30 项风险全部保持开放；这不是没有进展，而是证明已有本地控制与尚缺外部证明之间的边界已经重新准确。

按 Personal Cognitive Mirror 的 Inspect → Rank → Improve → Validate 反思，第 144 轮应重新排序。当前最高价值的本地候选是 R-013 的同步便携导出服务端字节上限与拒绝收据：客户端已在落盘前拒绝超过 50 MiB 的产物，但 API 仍会完整序列化并传输。下一轮可把上限放入共享契约，并对服务端最终 UTF-8 产物增加稳定拒绝语义；该改进仍不能消除组装时峰值内存，也不能替代封闭测试规模测量或最终的加密限时归档。

本轮没有关闭任何产品风险。所有依赖外部身份、设备、保留、备份、专家语料、数据许可、政策、托管材料、发布候选和具名责任人的门禁继续开放，实际外部配置继续停放。
