# 第 135 轮：动作跨窗口聚合单调性

日期：2026-08-11

状态：已完成

## 1. 范围、分类与验收标准

本轮分类为 F（Consistency Checking）。范围只有动作 7/30/90 日嵌套窗口的跨行集合关系。

验收标准固定为：先证明六项窗口聚合使用同一资格且数值非负；来源缺失窗口继续归一为全零；按 7→30→90 比较时，课次、完成组、次数、负荷、活动时间和距离全部非递减；共享响应 Schema 独立执行同样规则并提供精确错误路径。不得从有限点前缀重算完整窗口、补造活动、解释训练效果或修改 SQL、响应形状、分页、客户端、历史记录、计划和 AI。

## 2. 项目结构、设计、技术与实现功能

- `apps/api/src/insights/insights.service.ts`：新增来源动作窗口相邻单调性门禁，并在单窗口关系校验后、点校验前执行。
- `apps/api/src/insights/insights.service.test.ts`：主夹具补齐真实 30 日窗口和六项递增聚合；逐项覆盖较长窗口课次、完成组、次数、负荷、活动时间与距离减少。
- `packages/contracts/src/insights.ts`：共享动作响应 Schema 对固定三窗口增加相同的六字段嵌套集合约束，问题落到较长窗口的精确字段。
- `packages/contracts/src/insights.test.ts`：把六项窗口基线设为可观察非零值，并逐项覆盖 30 日窗口低于 7 日窗口。
- ADR-0129、架构、已实现 PRD、接口参考、路线图、风险登记册、项目状态和本档案：同步同资格前提、非负集合语义、限制与第 136 轮候选。

本轮没有改变合法响应形状、查询、集成夹具或客户端行为。

## 3. 实现方法

### 先证明同资格与非负前提

三个窗口都按同一用户、精确动作键、未删除训练、参考时刻上界和已完成组聚合，只改变时间下界。课次按具有已完成组的训练 ID 去重，完成组计数与次数、规范负荷、活动秒数和距离总和都来自相同集合。来源数值门禁已拒绝负值，因此扩大集合不能让任一总计减少。

### 先归一稀疏窗口

来源数组仍可乱序或缺失。身份与单窗口数值/关系通过后，构造器按固定 7/30/90 日查找来源；缺失身份等价于六项全零。空短窗口可以被非空长窗口包含，但已有短窗口不能在更长窗口中消失。

### 相邻比较形成传递约束

来源层使用同一六字段清单比较 7→30 和 30→90；响应层在固定窗口数组中独立执行相同检查。相邻规则已经通过传递性覆盖 7→90，无需重复跨两级判断。

### 保持统计权威边界

超过 180 个训练时公开点不是完整集合，不能用于重算任何窗口聚合。门禁只比较数据库或替代生产者提供的窗口值，不自动修正、补零或生成训练含义。

## 5. 发现的问题与经验

- 聚合字段是否单调取决于集合资格和数值符号；必须先证明两者，不能仅凭窗口天数下结论。
- 所有窗口值合法且单行关系成立，仍不能证明多个嵌套窗口可以同时成立。
- 稀疏来源应先归一再比较，既保留空短窗口，也阻止已有证据在较长窗口中静默消失。
- 相邻比较与共享字段清单减少了重复规则，并让来源与响应保持同一检查范围。
- 有限点前缀不能替代完整窗口聚合，即使二者在小样本测试中数值相同。

## 6. 全局状态、项目反思与下一步

本轮关闭了动作 7/30/90 日窗口之间不可能的六项聚合减少。它没有完全验证单个窗口的零证据关系。

按 Personal Cognitive Mirror 的 Inspect → Rank → Improve → Validate 反思，当前单窗口规则只有 `sessionCount <= completedSetCount`，仍允许零课次配非零完成组；完成组为零时，SQL 的次数、负荷、活动时间和距离也应全部为零。下一轮第 136 轮必须重新排序；当前最小候选是精确绑定零课次、零完成组和零测量总计，同时保留“有完成组但某项测量为零”的合法情形。不得反向要求训练量为正、补造数据或解释动作质量。

本轮未新增或关闭风险：跨窗口单调不证明单窗口零证据语义、训练记录真实性、动作执行安全、趋势意义、训练效果或真实用户理解。风险登记册全表时效复核、真实身份/设备/保留/备份与 AI 专家语料仍保持开放。
